# hyprland-dotfiles

My Hyprland setup, built from scratch on top of the stock config.

> Work in progress.

## Target system

- Ubuntu 26.04
- Hyprland 0.57 (Lua config: `hyprland.lua`)

## Components

| Role          | Tool          |
| ------------- | ------------- |
| Compositor    | Hyprland      |
| Terminal      | kitty         |
| Bar           | Waybar        |
| Launcher      | hyprlauncher  |
| Lock screen   | hyprlock      |
| Idle daemon   | hypridle      |
| File manager  | Nautilus      |
| Notifications | _TBD_         |
